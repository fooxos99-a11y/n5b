# نخب

مشروع مستقل لجهة مستقلة: الموقع والخادم وتطبيقا Android وiOS. معرّف التطبيق `sa.nukhab.app`، والمستودع `fooxos99-a11y/n5b`.

## الاستخدام

- npm ci لتثبيت الاعتماديات داخل هذا المجلد.
- npm run dev للواجهة.
- جهّز قاعدة MySQL جديدة منفصلة، ثم انسخ .env.example إلى .env.local وأكمل بيانات الاتصال قبل تشغيل npm run api.
- عند أول تشغيل على قاعدة فارغة ينشئ الخادم حساب المدير الوحيد من `MANAGER_LOGIN_NUMBER` بكل الصلاحيات، ولا يضيف بيانات افتراضية ما دام `SEED_DEFAULT_DATA=false`.
- npm run verify للتحقق الكامل وnpm run build لبناء الموقع.
- npm run build:mobile لبناء واجهة التطبيق.
- npm run native:android وnpm run native:ios لمزامنة المصادر. تجميع iOS يحتاج macOS وXcode.

لا يحتوي المشروع بيانات طلاب أو قواعد إنتاج أو أسرار أو جلسات أو مفاتيح توقيع أو إعدادات Firebase. أضف إعدادات التشغيل والتوقيع والإشعارات الخاصة بنخب عند الحاجة.
