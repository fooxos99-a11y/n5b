# توحيد بداية تشغيل التطبيق الأصلي

حالة الإصلاح المحلي قبل الرفع،16 أكتوبر2026: نُفذ الإصلاح محليًا في التطبيق الأصلي React/Vite/Capacitor. لم يُرفع إصدار جديد أو يُستبدل البناء22 المرسل لمراجعة App Store، ولم يحدث commit أو push ضمن هذا التعديل.

## السلوك

- أزيل مؤشر شاشة التشغيل الأصلية في iOS، وطابقت بداية Android اللون الأخضر نفسه دون الحلقة السابقة. تبقى شاشة النظام الثابتة القصيرة قبل تشغيل الواجهة، ولا تُوصف بأنها أنيميشن أصلي.
- صارت واجهة HTML المبكرة مالكة أنيميشن الشعار والزخرفة الموجودين، دون انتظار React. أزيلت نسخة React المكررة ونافذة التجربة القديمة، وأصبحت الاختبارات تستخدم المدخل الحقيقي.
- ينضم React إلى الخط الزمني الجاري، ويحمّل المسار وبياناته خلف الغطاء نفسه. يظهر الشعار ثابتًا إذا انتهت الحركة قبل اكتمال التجهيز، ثم تتلاشى الواجهة مرة واحدة. لا يعاد الأنيميشن عند التنقل أو إعادة التركيز داخل الوثيقة نفسها.
- بعد15 ثانية من تعثر البداية يظهر نص واضح وإعادة المحاولة، حتى إذا لم يصل ملف React. فشل الشعار يعاد بطلب جديد لتجاوز احتفاظ WebKit بالصورة الفاشلة، دون إعادة تحميل التطبيق الجاهز. تعطل React يكشف نافذة الخطأ المعتمدة ولا يحبسها خلف الغطاء.
- روعيت حركة النظام المخفضة، وRTL، وتعطيل التفاعل خلف البداية، واستعادة لوحة المفاتيح، وتقديم خط Cairo مبكرًا من تعريف الخط المشترك. أضيف متحكم البداية والشعار الأبيض إلى التخزين الأولي للويب. بقي تحميل الإجراءات اللاحقة بالمؤشر المشترك المعتمد.
- لم يتغير المصحف أو ألوان الصفحات أو صلاحيات الحسابات أو سياسة تنفيذ القرآن عند المشرف، ولم تدخل ملفات Expo في الإصلاح.

## التحقق

- نجح `npm run verify` على مساحة التطبيق الأصلي المعزولة: الامتثال وLint و782 اختبارًا وتدقيق الاعتماديات بصفر ثغرات وبناء الويب. بعد إضافة حالتي التخزين الأولي اجتاز `npm test` كاملًا784 اختبارًا، وLint للاختبارات الجديدة. لا ينسب التدقيق النظيف إلى مساحة تحويل Expo المختلطة أو عوائقها السابقة.
- نجح `npm run build:mobile`، ثم مزامنة iOS وAndroid وبناء APK Android Debug. طابقت بداية التشغيل داخل APK المصدر الحالي وملفات iOS المزامنة حرفيًا. كانت معالجة مسارات Gradle والاعتماد الموجود محلية فقط دون تغيير إصدار اعتماد أو lockfile أو إعداد نشر.
- اجتازت26 حالة في Chromium وWebKit:320 و390 و1440 والاتجاه الأفقي، تأخير JavaScript والبيانات، احتفاظ عنصر الأنيميشن بهويته، فشل الحزمة والشعار وإعادة المحاولة، تعطل React، تقليل الحركة، واستعادة حسابات المدير والطالب والمشرف. شمل الدخول401 ثم النجاح، غياب الحساب بعد الرفض، وعدم تكرار طلب الدخول أو إعادة الأنيميشن.
- اجتازت3 حالات استمرار مؤشر التحميل عند تبدل مراحل لاحقة، و3 حالات استعادة الحساب والإحصائيات بعد تعطل التخزين المحلي وفشل الشبكة ثم عودتها. مجموع حالات المتصفح32. كانت الطلبات وبيانات الدخول معزولة عن الإنتاج.
- واجه التشغيل الأول لفحص إعادة الاتصال مهلة reload أثناء البناء المتزامن؛ اجتاز تشغيله المنفرد لاحقًا المقاسات الثلاثة. بقية إخفاقات التطوير ومعالجتها موثقة في ملخص التحقق، ولم تُعطل قواعد لتجاوزها.
- لم يحدث بناء iOS أصلي باستخدام Xcode أو تشغيل على iPhone أو Android فعلي؛ فحص المتصفحات وبناء APK ومزامنة iOS لا يثبت هذه الأجهزة.
