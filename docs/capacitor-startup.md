# توحيد بداية تشغيل التطبيق الأصلي

حالة الإصدار،16 أكتوبر2026: رُفع إصلاح بداية التشغيل للتطبيق الأصلي إلى GitHub وTestFlight بالإصدار1.0.19 (23)، وأُرسل البناء نفسه إلى App Store وأصبح بانتظار المراجعة. استُبدل طلب1.0.18 (22) السابق. لا يشمل الرفع تحويل Expo.

## السلوك

- أزيل مؤشر شاشة التشغيل الأصلية في iOS، وطابقت بداية Android اللون الأخضر نفسه دون الحلقة السابقة. تبقى شاشة النظام الثابتة القصيرة قبل تشغيل الواجهة، ولا تُوصف بأنها أنيميشن أصلي.
- صارت واجهة HTML المبكرة مالكة أنيميشن الشعار والزخرفة الموجودين، دون انتظار React. أزيلت نسخة React المكررة ونافذة التجربة القديمة، وأصبحت الاختبارات تستخدم المدخل الحقيقي.
- ينضم React إلى الخط الزمني الجاري، ويحمّل المسار وبياناته خلف الغطاء نفسه. يظهر الشعار ثابتًا إذا انتهت الحركة قبل اكتمال التجهيز، ثم تتلاشى الواجهة مرة واحدة. لا يعاد الأنيميشن عند التنقل أو إعادة التركيز داخل الوثيقة نفسها.
- بعد15 ثانية من تعثر البداية يظهر نص واضح وإعادة المحاولة، حتى إذا لم يصل ملف React. فشل الشعار يعاد بطلب جديد لتجاوز احتفاظ WebKit بالصورة الفاشلة، دون إعادة تحميل التطبيق الجاهز. تعطل React يكشف نافذة الخطأ المعتمدة ولا يحبسها خلف الغطاء.
- روعيت حركة النظام المخفضة، وRTL، وتعطيل التفاعل خلف البداية، واستعادة لوحة المفاتيح، وتقديم خط Cairo مبكرًا من تعريف الخط المشترك. أضيف متحكم البداية والشعار الأبيض إلى التخزين الأولي للويب. بقي تحميل الإجراءات اللاحقة بالمؤشر المشترك المعتمد.
- لم يتغير المصحف أو ألوان الصفحات أو صلاحيات الحسابات أو سياسة تنفيذ القرآن عند المشرف، ولم تدخل ملفات Expo في الإصلاح.

## التحقق

- نجح `npm run verify` الحالي على مساحة التطبيق الأصلي المعزولة: الامتثال وLint و784 اختبارًا وتدقيق الاعتماديات بصفر ثغرات وبناء الويب. لا ينسب التدقيق النظيف إلى مساحة تحويل Expo المختلطة أو عوائقها السابقة.
- نجح `npm run build:mobile`، ثم مزامنة iOS وAndroid وبناء APK Android Debug. طابقت بداية التشغيل داخل APK المصدر الحالي وملفات iOS المزامنة حرفيًا. كانت معالجة مسارات Gradle والاعتماد الموجود محلية فقط دون تغيير إصدار اعتماد أو lockfile أو إعداد نشر.
- اجتازت26 حالة في Chromium وWebKit:320 و390 و1440 والاتجاه الأفقي، تأخير JavaScript والبيانات، احتفاظ عنصر الأنيميشن بهويته، فشل الحزمة والشعار وإعادة المحاولة، تعطل React، تقليل الحركة، واستعادة حسابات المدير والطالب والمشرف. شمل الدخول401 ثم النجاح، غياب الحساب بعد الرفض، وعدم تكرار طلب الدخول أو إعادة الأنيميشن.
- اجتازت3 حالات استمرار مؤشر التحميل عند تبدل مراحل لاحقة، و3 حالات استعادة الحساب والإحصائيات بعد تعطل التخزين المحلي وفشل الشبكة ثم عودتها. مجموع حالات المتصفح32. كانت الطلبات وبيانات الدخول معزولة عن الإنتاج.
- واجه التشغيل الأول لفحص إعادة الاتصال مهلة reload أثناء البناء المتزامن؛ اجتاز تشغيله المنفرد لاحقًا المقاسات الثلاثة. بقية إخفاقات التطوير ومعالجتها موثقة في ملخص التحقق، ولم تُعطل قواعد لتجاوزها.
- اكتمل بناء Xcode الموقّع والأرشفة والتصدير والرفع من GitHub Actions. طابقت الحزمة متحكم البداية والمصدر، وثبت غياب مؤشر التحميل من شاشة iOS المترجمة، وتطابق2420 ملف مصحف مع مصدر الإصدار، بما فيها604 خطوط و604 تخطيطات صفحات. لم يحدث تشغيل على iPhone أو Android فعلي؛ المتصفح والمحاكي والبناء لا يثبتان تجربة هذه الأجهزة.

## إصدار1.0.19 (23)

- رُفع مصدر التطبيق الأصلي `2bb069938f32b0f5c01afa25da475d5dd5ea1558` إلى فرعه الحالي، وبقي main وفرع Expo دون تغيير. ملفات تحويل Expo مستبعدة من فرق الإصدار.
- اكتمل بناء Xcode وتصدير IPA والرفع إلى Apple بنجاح. تأخر نقل الحزمة نحو17 دقيقة، ثم أكد السجل `UPLOAD SUCCEEDED with no errors`؛ لم تُكرر محاولة بناء التطبيق بسبب التأخر.
- أكدت Apple أن معالجة البناء `VALID` وإتاحته `IN_BETA_TESTING` داخل مجموعة الاختبار القائمة. شاهد الإتاحة في `outputs/startup-review/testflight-23-availability.json` وفحص IPA في `outputs/startup-review/ipa-23-validation.json`.
- رفضت Apple أول استعلام تحقق لأنه جمع مرشحين للعلاقات. صُحح إلى مرشح علاقة واحد بعد التحقق المستقل من ملكية المجموعة، وأضيف شرط اختبار يمنع تكرار الخطأ. اجتازت أدوات الإصدار18 اختبار Python للنجاح والفشل والصلاحيات ومنع المجموعة أو البناء الخطأ والتكرار.
- فشل مسار App Store الآلي بصلاحية403 عند إلغاء الطلب السابق؛ مفتاح الرفع لا يسمح بهذه العملية. لم تُوسع صلاحياته. أُكمل الإلغاء والحفظ واختيار البناء والإرسال من جلسة المالك المصرح بها، وتأكدت حالة `Waiting for Review` للبناء1.0.19 (23). احتُفظ بوصف «برنامج نخب التعليمي» وبيانات دخول المراجع القائمة والنشر بعد الموافقة، وحُدثت ملاحظات الإصدار والمراجعة.
- ملف `data1.yml` يحفظ بيانات الوجهتين الحالية وطريقة الإرسال الفعلية. ملخص الشواهد `outputs/startup-review/release-1.0.19.json` وصورة الحالة `outputs/startup-review/app-store-1.0.19-23-waiting-review.png`.
- المراجعة لم تعتمد بعد، ولم يُثبت تثبيت النسخة على iPhone. عوائق مساحة التحويل السابقة، ومنها5 ثغرات عالية في أدوات Expo وDoctor20/21 وأخطاء Lint السبعة في السكربت السابق، خارج هذا الإصدار ولم يُعد فحصها أو الادعاء بإغلاقها.
