## الخطأ المكتشف والإصلاح

فشل أول restore في مرحلة `database-file-check` قبل إنشاء DB. على Android يعيد Expo SQLite مسارًا مطلقًا خامًا بينما Expo File يحتاج رابط `file:///`. أصلح وكيل التطبيق [تحويل الدليل](../../mobile/src/domain/probeDatabaseUri.ts) لنفس موقع SQLite، مع رفض المسار المفقود أو النسبي، وأعاد الفحص اجتيازه. [التشخيص](../../mobile/src/domain/probeFailure.ts) يعرض مرحلة ونوعًا ورمزًا من قوائم ثابتة، دون رسالة native أو SQL أو مفتاح أو stack.

لم يُعد بناء APK لهذا الإصلاح؛ أُعيد تشغيل Metro مع مسح cache، وسُجلت بصمات JS النهائية التي شُغلت، ومنها ملفا التحويل والتشخيص. تقرير المحاكي لا يحتسب اختبارات وكيل التطبيق أو فحصه على المتصفح دليلًا من جهاز فعلي.

## فقد المفتاح بصورة قابلة للتراجع

بعد حفظ بيانات التجربة وإيقاف App، أُعيدت تسمية `shared_prefs/SecureStore.xml` إلى اسم احتياطي فريد **داخل sandbox التطبيق نفسه**. لم يُقرأ محتواه أو ينسخ خارجه. عند إعادة App ومحاولة الاستعادة ظهر `database-file-check / missing-key`، ولم يُنشأ ملف SecureStore بديل.

بصمة DB قبل الحارس وبعده متطابقة:

```text
D9CE61FC427295285918DBA239D5D01D0ED9C31450620BE40A44C9F795E3BC99
```

أوقف `finally` التطبيق وأعاد ملف SecureStore الأصلي. وبعد فتح COLD جديد نجحت استعادة المسودة والجلسة بتاريخ الحفظ نفسه. يثبت ذلك حفظ بيانات التجربة ورفض إنشاء مفتاح بديل؛ لا يثبت ترحيل مفتاح Capacitor القديم أو استعادة نسخة احتياطية على جهاز آخر.

## إغلاق عمليات الفحص وحدود الإنجاز

أُزيل ربط `8093` لهذا serial، وأُوقف المحاكي بعد مطابقة اسمه وPID، وأُوقفت عملية Metro النهائية `436` بعد مطابقة سطر تشغيلها. تحقق غياب العمليتين وتحرير المنافذ `8093/5584/5585`. حُذفت نسخة APK المؤقتة فقط من مجلد AVD بعد التحقق من المسار والاسم وعدم كونها reparse point؛ بقي تعريف AVD المملوك والأدلة المحلية. لم ينفذ `adb kill-server` أو حذف مجلد محاكي آخر.

تبقى تجربة LiveKit دون grant، وترحيل SQLite/keychain القديم، والمسودة التحريرية والمزامنة، وتشغيل iOS أو جهاز Android فعلي غير مثبتة. ترخيص توزيع خطوط المصحف لم يُحسم، ولا نشر أو رفع أو SQL إنتاجي ضمن الفحص.
