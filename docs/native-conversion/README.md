# متابعة تحويل نخب

بدأ التنفيذ المحلي في 14 أكتوبر 2026. المرجع الرئيسي هو [ملف الخطوات](../native-conversion-plan.md)، وفيه حالات كل خطوة وأدلة التحقق والعوائق.

متابعة هذه الدفعة في [مطابقة الطالب والتقويم](native-student-parity.md). أدلة المراحل الوظيفية ودفعة الأساس والبوابات السابقة تخص مصادرها وتواريخها؛ الأعداد والبصمات وحالات MySQL أدناه لا تُحمَل على المصدر أو بيئة التشغيل الحالية.

[الأخبار والإشعارات](native-communications.md) هي آخر مرحلة وظيفية قبل دفعات مطابقة التصميم: W06-33 وW06-34 done؛ كان الإجمالي عند إغلاقها60/196 والمتبقي136. اجتازت638 اختبارًا و154 عقدًا و24 مجموعة متصفح/6 تنويعات/53 صورة، و27 فحصAndroid/21 صورة/122HTTP. تدقيق المصدر والصور والتنظيف اجتاز، وMySQL3310 المملوك stopped مع حفظ263 قاعدة. W07-16 verify دون وجهة مخترعة، وW10 والأجهزة الفعلية مفتوحة. verify الكامل ما زال يفشل عند5 ثغراتExpo وDoctor20/21 و7 أخطاءLint السابقة فيالجذر؛ التفاصيل والشواهد فيالتقرير.

## التحقق السابق للأساس

في مرحلة الأساس اجتاز `npm run verify` كاملًا: فاحص AGENTS وLint و**779 اختبارًا دون فشل أو تخطي** وتدقيق الاعتماديات دون ثغرات وبناء الموقع. النتيجة التاريخية محفوظة في [تقرير تحقق الجذر](evidence/root-validation.json).

توقفت المحاولة الأولى عند `structuredClone` في اختبار المصحف الموجود مسبقًا. ثبت وجود الدالة في Node المحلي، وأن إعداد ESLint يطبق globals على اختبارات `.js` فقط. أُصلح نطاق الإعداد ليشمل `.mjs` مع القواعد نفسها، ثم اجتازت السلسلة كاملة. لم يُعدّل اختبار المستخدم ولم تُعطّل قاعدة لإخفاء فشل.

فاحص الحصر `node scripts/check-native-inventory.mjs` اجتاز مطابقة الحصر بالمصدر. مرجع الأمن له 25 اختبارًا مستهدفًا ناجحًا ضمن مجموعة اختبارات المشروع؛ لا تجمع أعداد هذه الاختبارات مع العدد الكامل على أنها حالات مستقلة إضافية.

نتائج الجوال منفصلة عن تحقق الموقع: تجميع JavaScript أو نجاح اختبار SQLite محلي لا يثبت تشفير SQLCipher أو ترحيل Capacitor أو مكالمة فعلية على الجهازين.

في الجوال، اجتازت الأنواع وLint و165 اختبارًا وتصدير Hermes للمنصتين. [دليل العمليات](native-operations.md) و[نتائج الواجهة](../../mobile/evidence/operations-ui.json) يثبتان33 مجموعة تحقق عند320 و390 و1440 في الثيمين، مع614 طلبًا من الواجهة و117 طلب تهيئة وتحقق و103 صور و89 بصمة مصدر. [الدليل السابق للدخول](../../mobile/evidence/auth-validation.json) محفوظ لنسخته وتاريخه، ومنفصل عن [سجل W01](../../mobile/evidence/validation.json). `npm run verify` الخاص بالجوال يبقى غير مجتاز بسبب تنبيه node-forge في أدوات Expo CLI.

نجح بناء Android debug الجديد للمحاكي x86_64 مع وحدتي الموقع ونسخ الرابط؛ شملت المرحلة122 ملفًا وتنظيف مجلد البناء المؤقت. النسخة تحتاج Metro ولا تضم JavaScript مدمجًا؛ إنتاج APK وحده لا يثبت تشغيل الواجهة أو SQLCipher أو مكالمة فعلية. سجلات تشغيل المحاكي محفوظة بصورة مستقلة لكل جزء.

اجتاز [تشغيل وظائف الحسابات علىAndroid](evidence/native-operations-emulator.json)21 تحققًا فعليًا مع92 طلبHTTP و18 صورة و261 بصمة مصدر متطابقة. شمل استعادة الطالب والمشرف والإداري، والحضور، ورفض إذن الموقع ثم السماح أثناء الاستخدام والتحضير بإحداثيات محاكي اصطناعية. تنظيف العمليات والمنافذ نجح، وأوقفMySQL المملوك مع حفظ قواعد الاختبار. [ملخص الأدلة الحالي](../../mobile/evidence/operations-validation.json) يفصل هذه النتيجة عن المتصفح والأجهزة الفعلية.

شُغلت النسخة فعليًا على محاكي نخب مستقل: اجتازت الهوية وعينات المصحف والتحديد عبر سطرين، والحفظ المشفر ثم الإيقاف الكامل والاستعادة بنفس التاريخ وفصل الحساب والجهة. فقد المفتاح منع إنشاء بديل وأبقى DB كما هي، وإعادة الأصل أعادت البيانات. [تقرير المحاكي](android-emulator.md) يسجل تصحيح خطأ URI والدليل النهائي وبصمات JS وإغلاق العمليات. هذا دليل Android محاكى، وتبقى الأجهزة الفعلية وiPhone والمكالمة والترحيل مفتوحة.

## الحدود التشغيلية

لم يُنفذ نشر أو SQL إنتاجي أو تعديل لبيانات الاستضافة. قاعدة العقود الجديدة محلية وببيانات اصطناعية، وتُترك قواعد الاختبار التي تنشأ من تشغيل الاختبار دون حذف تلقائي. لم تُمس تغييرات المصحف الحالية.

خطوات W00 المنجزة هي الحصر ومصفوفة الصلاحيات وحصر التخزين وتجهيز بيانات الاختبار. تبقى مرجع بقية الواجهات وعقود الحفظ الكاملة وقياس الأجهزة مفتوحة، ويستمر تجهيز التجربة المستقل دون اعتبار المرحلة مغلقة.

بعد مرحلة الإدارة بلغ الإجمالي **39 من196 خطوة done**. تشملW06-07 إلىW06-13: المشرفون والإداريون وربط الحلقات وإنشاء الخطط والمحفوظ والانتظار والاستمرار والإغلاق والحذف والإيقاف والاستئناف. [شاهد المرحلة](native-management.md) يثبت48 مجموعة واجهة على320 و390 و1440 في الثيمين،82 صورة و98 بصمة مصدر و137 تحققHTTP/MySQL. فحص التطبيق حينها217 اختبارًا والأنواع وLint وHermes اجتاز، وتدقيقه بقي متوقفًا عندnode-forge. فحص الجذر لتلك المرحلة779 اختبارًا والتدقيق والبناء اجتاز. الأدلة السابقة محفوظة لنسخها؛ بقية الحسابات والأجهزة والترحيل والمكالمات مفتوحة، والنقاط لا تغلق الترتيب والتحضير لا يفرض منعًا جديدًا غير موجود في الموقع.
