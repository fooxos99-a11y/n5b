# مرجع واجهات نخب قبل التحويل

هذا مرجع محلي للخطوة W00-03 وتجهيز قياس W00-08. شغّل التصوير واجهات المصدر الحالية ببيانات اصطناعية واعتراض جميع طلبات API محليًا؛ لم يُستخدم دخول لحساب تشغيل أو بيانات إنتاج.

## الشاشات المصورة

| الشاشة | المقاسات | النطاق |
|---|---|---|
| بداية التطبيق | 390 و1440 بارتفاع 900 | الشعار والأنيميشن والزخارف الحالية |
| تسجيل الدخول | 390 و1440 بارتفاع 900 | شاشة المصدر الفعلية وحقول الدخول |
| رئيسية الطالب | 390 و1440 بارتفاع 900 | واجهة المصدر الفعلية ببيانات الطالب الاصطناعية |
| المصحف | 390 و1440 بارتفاع 900 | قارئ المصحف الحالي وموارده المحلية في fixture |

حُفظت ثماني صور في `outputs/native-conversion/baseline/`. راجعت صورة الدخول عند 390 وصورة المصحف عند 1440 بصريًا؛ اجتاز الفحص الآلي عدم تجاوز عرض الصفحة وعدم وجود أخطاء JavaScript للشاشات المصورة. يحمل [التقرير](evidence/web-baseline.json) أسماء الصور وتوقيت الفتح وبصمات ملفات المصدر قبل التصوير وبعده.

يكمل [مرجع الحسابات والتسجيل](role-web-reference.md) هذا الدليل بـ22 صورة للمدير والمشرف والإداري والتسجيل على المقاسين وفي الثيمين. تبقى صور كل دليل محددة بنطاقه وبصمات مصادره.

## إعادة التصوير

من جذر نخب، شغّل خادم Vite محليًا في نافذة طرفية:

```powershell
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 3141 --strictPort
```

ثم شغّل [أداة التصوير](../../scripts/capture-native-web-baseline.mjs):

```powershell
node scripts/capture-native-web-baseline.mjs
```

الناتج صور محلية مهملة من Git وتقرير أدلة داخل الوثائق. لا يغيّر التصوير بيانات الخادم؛ يشمل الاعتراض أيضًا طلب تجهيز مساحة الطالب المحلي، وهو POST في العقد الحالي.

## ما بقي للتحقق

لا تمثل الصور مرجعًا مكتملًا لكل شاشة إدارة أو مشرف أو لكل ثيم. تبقى W00-03 في `verify` حتى استكمال المرجع المطلوب ومراجعة الهوية والثيمين مع الحصر النهائي. توقيت الفتح المسجل عينة Chromium محلية تشمل بيئة التطوير والبيانات المحاكاة؛ لا يعادل قياس جهاز ولا يسمح باعتماد حدود الأداء أو وضع W00-08 في `done`.

توجد تعديلات مستخدم على المصحف؛ عند تغيّر ملفات مرجعه المؤثرة يعاد التصوير للجزء الذي تغير فقط، وتُحفظ بصمات المصدر في التقرير. لا يعاد فحص مرجع لم يتغير بلا سبب.
